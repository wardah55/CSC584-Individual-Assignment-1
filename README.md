## Project Description
A simple Personal Profile Web Application built using HTML, Java Servlet, and JavaServer Pages (JSP). It collects user data via an HTML form, processes it in a Servlet, and displays it on a styled JSP page.

## Technologies Used
* Java (JDK)
* Java Servlet
* JavaServer Pages (JSP)
* HTML5 & CSS3
* Apache NetBeans IDE
* GlassFish / Tomcat Server

## How to Run the Application
1. Open the project in NetBeans IDE.
2. Make sure you have a local server (GlassFish or Apache Tomcat) configured.
3. Right-click the project and select **Clean and Build**.
4. Right-click the project and select **Run**.
5. The browser will open the `index.html` form. Fill in the details and submit.
